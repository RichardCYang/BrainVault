# 기능

## 워크스페이스 및 편집기

BrainVault는 간결한 문서 트리와 자동 제목 저장을 갖춘 페이지 중심 워크스페이스를 사용합니다. 충돌에 강한 브라우저 초안 저널이 서버의 더 최신 버전을 덮어쓰지 않으면서 승인되지 않은 제목 및 블록 편집 내용을 복원합니다.

페이지와 컬렉션은 한국어/영어 검색, 카테고리, 피부색 변형, 최근 선택, 재사용 가능한 최대 512 KB의 사용자 지정 PNG, JPEG, WebP 또는 ICO 이미지 아이콘과 함께 Unicode Emoji 17 아이콘을 지원합니다. 페이지는 중첩, 보관, 또는 점 3개 메뉴에서 영구 삭제할 수 있으며 검색은 페이지 제목과 블록 콘텐츠를 모두 대상으로 합니다.

### 페이지 커버 이미지

각 일반 페이지는 제목 위에 넓은 커버를 표시할 수 있습니다. `public/img/default_cover`의 다섯 이미지 중 하나를 선택하거나 PNG, JPEG, WebP 이미지를 업로드하세요. 닫혀 있는 picker는 전체 크기 이미지를 가져오지 않으며, 대화상자가 열릴 때만 작은 WebP 미리보기가 할당됩니다. 브라우저 측 최적화는 기존 페이지 업데이트 API가 저장하기 전에 사용자 지정 커버를 2 MB 이하로 제한하고, 서버 검증은 선언된 이미지 유형과 바이너리 signature를 모두 확인합니다.

소유자는 언제든 커버를 교체하거나 제거한 뒤 나중에 다시 추가할 수 있습니다. **위치 조정(Reposition)** 모드는 직접 포인터 드래그와 가로/세로 슬라이더를 지원합니다. 선택한 초점 위치는 0~100 좌표로 저장되고 `object-fit: cover` 및 `object-position`으로 렌더링됩니다. 커버 원본과 위치 메타데이터는 워크스페이스 백업 및 복원에 포함됩니다.

## 동시 편집을 지원하는 페이지 및 컬렉션 공유

### 직접 페이지 공유

일반 페이지를 열고 **공유(Share)**를 선택해 로그인 ID로 기존 BrainVault 계정을 추가합니다. 직접 페이지 공유는 해당 페이지에 `EDIT` 권한을 만듭니다. 직접 권한은 페이지 소유자만 만들거나 취소할 수 있습니다. 유효 `ADMIN` 접근 권한이 있는 사용자는 항목을 확인할 수 있지만 소유자가 발급한 접근 권한을 취소할 수는 없습니다. 직접 페이지 협업자는 공유 페이지를 편집할 수 있지만 직접 권한만으로는 소유자의 주변 페이지 계층이 노출되지 않습니다.

보관된 일반 페이지는 새 직접 권한을 받을 수 없고 실시간 협업도 사용할 수 없습니다. 기존 직접 권한은 페이지가 보관된 동안 유지되며 페이지를 복원하면 다시 사용할 수 있습니다.

### 컬렉션 공유

**사용자 지정 컬렉션**은 기존 BrainVault 계정에 `READ`, `WRITE`, `ADMIN`의 세 권한 중 하나로 공유할 수 있습니다. 권한은 컬렉션과 중첩된 하위 페이지를 포함한 계층의 모든 문서 페이지에 적용됩니다. 컬렉션 안에 새로 만든 페이지는 해당 권한을 상속하고, 페이지 하위 트리를 컬렉션 안이나 밖으로 이동하면 유효 컬렉션 범위가 업데이트됩니다.

컬렉션 공유 UI를 열려면 사이드바에서 사용자 지정 컬렉션의 **이름**을 클릭해 컬렉션 랜딩 뷰를 표시한 다음 **페이지 추가(Add page)** 옆의 **컬렉션 공유(Share collection)**를 선택합니다. 가상 **기본 컬렉션(Default Collection)**, 개별 문서가 열려 있는 경우, 또는 컬렉션 권한이 `READ`/`WRITE`뿐인 협업자에게는 이 컨트롤이 표시되지 않습니다.

| 권한 | 동작 |
| --- | --- |
| `READ` | 공유 컬렉션을 탐색하고 멤버 문서를 읽습니다. 브라우저는 실시간 Yjs 변경을 받을 수 있지만 서버 측 협업 쓰기는 거부됩니다. |
| `WRITE` | 읽기와 함께 공유 문서의 제목 및 블록을 편집합니다. 공유 및 페이지 관리 컨트롤은 사용할 수 없습니다. |
| `ADMIN` | 읽기/쓰기와 함께 공유된 컬렉션 범위 내에서 컬렉션 공유 및 멤버 페이지 관리를 수행합니다. 해당 컬렉션 밖으로 페이지 이동, 컬렉션 루트의 영구 삭제, 소유자가 발급한 직접 페이지 권한 취소는 거부됩니다. |

특정 사용자에 대해서는 멤버 페이지의 직접 페이지 `EDIT` 권한보다 컬렉션 권한이 우선합니다. 따라서 오래된 직접 `EDIT` 권한이 있어도 컬렉션 `READ` 권한이 있으면 해당 페이지는 읽기 전용으로 유지됩니다. 컬렉션 권한을 제거하면 우선순위가 낮던 직접 페이지 권한이 다시 유효해질 수 있습니다.

일반 문서에 유효 협업자가 하나라도 설정되어 있는 동안 페이지 제목과 블록 문서는 인증된 WebSocket 연결의 Yjs 공유 문서를 통해 동기화됩니다. 동시 텍스트 및 구조 변경은 자동 병합되고, 활성 협업자와 현재 편집 위치가 페이지 헤더에 표시되며, 일시적인 연결 끊김 중의 편집은 재연결 후 병합됩니다. `READ` 컬렉션 협업자는 실시간 문서와 동기화 상태를 유지할 수 있지만 Yjs 쓰기를 제출할 수는 없습니다.

첨부파일 바이트는 계속 인증된 업로드/다운로드 API를 사용합니다. 서버는 정식 첨부파일 블록을 Yjs room에 게시하므로 쓰기 가능한 협업자가 이를 받으면서도 클라이언트가 파일 메타데이터를 위조할 수 없습니다. Yjs 업데이트는 MariaDB에 영속적으로 저장되며, 검색·렌더링·내보내기·백업 호환성을 위해 주기적으로 일반 페이지/블록 테이블로 materialize됩니다.

공유 페이지 보관, 페이지 하위 트리 영구 삭제, 컬렉션 멤버십 변경, 공유 권한 변경/제거, 전체 워크스페이스 복원은 모두 persistence transition과 recovery fence를 조정하여 오래된 브라우저 상태가 더 최신 접근 generation을 덮어쓰지 못하게 합니다.

프로토콜과 영속성 모델은 [페이지 및 컬렉션 공유와 실시간 협업](../../collaboration/2026-07-29/collaboration.ko.md)을, 컬렉션 전용 UI·역할 모델·상속 규칙·API·백업 동작·문제 해결은 [컬렉션 공유](../../collaboration/2026-09-02/collection-sharing.ko.md)를 참고하세요.

### 키보드 및 블록 컨트롤

| 동작 | 결과 |
| --- | --- |
| `Enter` | 현재 블록 아래에 블록을 삽입합니다. |
| `Shift + Enter` | 같은 블록 안에 줄바꿈을 추가합니다. |
| 빈 블록에서 `Backspace` | 블록을 제거하고 중첩된 자식을 그 자리에 승격한 뒤 이전 블록으로 포커스를 이동합니다. 네트워크 완료 여부가 불명확한 경우 같은 삭제 receipt로 재시도합니다. |
| `/` | 블록 유형 메뉴를 엽니다. |
| `Ctrl/Cmd + B` | 선택한 텍스트에 굵게 서식을 적용합니다. |
| `Ctrl/Cmd + I` | 선택한 텍스트에 기울임 서식을 적용합니다. |
| `Ctrl/Cmd + Shift + M` | 선택한 텍스트를 인라인 LaTeX 수식으로 감쌉니다. |
| 점 6개 핸들 드래그 | 현재 계층 안에서 블록 순서를 변경합니다. |

유용한 슬래시 명령은 다음과 같습니다.

```text
/h1  /h2  /h3  /todo  /quote  /callout  /table  /database  /gantt  /board  /bookmark  /ai  /math  /code  /divider  /image  /file
```

인라인 서식은 굵게, 기울임, 취소선, 코드, 수식, 링크, 텍스트 색상, 왼쪽/가운데/오른쪽/양쪽 맞춤 블록 정렬을 지원합니다. 드래그 앤 드롭 순서 변경은 중첩 콘텐츠도 지원합니다.

표 블록에는 행, 열, 헤더 컨트롤이 있습니다. 셀은 화살표 키 이동을 지원하며, `Enter`는 현재 열의 아래쪽으로 이동하고 마지막 셀에서 `Tab`을 누르면 행이 추가됩니다.

## 데이터베이스 및 칸반 블록

`/database`를 입력해 데이터베이스 블록을 만듭니다. 각 데이터베이스는 필수 제목 속성 하나와 선택적인 텍스트, 숫자, 단일 선택, 다중 선택, 체크박스, 날짜, URL 속성을 가집니다.

표, 보드, 목록 뷰는 같은 행 집합에서 동작합니다. 각 뷰는 자체 이름, 레이아웃, 표시 속성, 필터, 정렬 순서, 보드 그룹화를 저장합니다. 편집기에는 뷰 탭, 속성/필터/정렬 popover, 뷰 내 검색, 분할 New 버튼, 투명한 열 헤더, 색상이 있는 선택 pill이 포함됩니다.

속성 및 행 변경은 `metadata.database`에 저장되고, 검색 가능한 텍스트 요약은 `markdown`에 유지됩니다.

칸반 보드는 제목, 그룹, 카드를 직접 편집할 수 있습니다. 카드는 이모지와 기본, 분홍, 노랑, 파랑, 연두, 보라, 복숭아 파스텔 테마를 사용할 수 있습니다. 점 6개 카드 핸들을 드래그해 카드 순서를 바꾸거나 그룹 간 이동할 수 있으며, 화살표 컨트롤은 터치 장치와 키보드 사용자에게 같은 이동 기능을 제공합니다.

## 간트 타임라인 블록

`/gantt`를 입력하면 고정 작업 표와 가로로 스크롤되는 날짜 그리드를 결합한 프로젝트 타임라인을 만들 수 있습니다. 각 작업은 제목, 상태, 담당자, 시작/종료 날짜, 진행률을 저장합니다.

주, 월, 분기 배율을 사용할 수 있고 오늘로 이동하거나 인접 날짜 범위로 이동할 수 있으며 주말 음영도 선택할 수 있습니다. 작업 막대를 드래그하면 전체 일정을 이동하고, 양쪽 끝을 드래그하면 기간을 조정하며, 왼쪽/오른쪽 화살표 키도 사용할 수 있습니다. `Shift`를 누른 채 화살표 키를 누르면 작업을 이동하는 대신 종료 날짜를 조정합니다.

간트 데이터는 `metadata.gantt`에 저장되고 제한된 길이의 평문 요약은 `markdown`에 유지되므로 페이지 검색에서 타임라인 제목, 작업, 상태, 담당자, 날짜, 진행률을 찾을 수 있습니다.

## LaTeX 수식

`/math`를 입력하면 실시간 KaTeX 미리보기가 있는 가운데 정렬 display-formula 블록을 만들 수 있습니다. 다음과 같이 주변 구분자 없이 소스를 입력합니다.

```text
\frac{-b \pm \sqrt{b^2-4ac}}{2a}
```

인라인 수식은 텍스트를 선택하고 `∑` 도구 모음 버튼을 누르거나 `Ctrl/Cmd + Shift + M`을 사용합니다. BrainVault가 선택 영역을 `\(...\)`로 감쌉니다. Markdown 블록은 `$...$`와 `$$...$$`로 구분된 display 수식도 인식합니다.

수식 렌더링은 정제되며 신뢰 명령이 비활성화된 KaTeX를 사용합니다.

## AI 대화 블록

`/ai`를 입력하면 질문과 AI 답변을 양쪽 채팅 transcript 형태로 저장할 수 있습니다. 질문은 오른쪽 정렬 bubble로, 답변은 AI 식별 정보와 응답 메타데이터가 있는 왼쪽 정렬 bubble로 표시됩니다.

아이콘 picker에는 설정된 AI 제공자 선택지가 표시됩니다. 제공자 아이콘, 자유 형식 모델 이름, 로컬 답변 날짜/시간, 질문, 답변은 `metadata.aiChat`에 저장됩니다. 길이가 제한된 텍스트 요약도 `markdown`에 기록되므로 제공자, 모델, 질문, 답변을 검색할 수 있습니다. 읽기 모드는 대화 표현을 유지하면서 설정 컨트롤을 숨깁니다.

## 북마크 블록

`/bookmark`를 입력해 웹 북마크 컬렉션을 만듭니다. HTTP 또는 HTTPS URL을 붙여넣으면 BrainVault가 서버에서 페이지 메타데이터를 가져옵니다.

블록은 두 가지 뷰를 지원합니다.

- **목록(List):** favicon과 제목이 포함된 간결한 행
- **갤러리(Gallery):** OpenGraph 썸네일, 제목, 설명, favicon, 사이트 이름이 있는 반응형 카드

북마크는 새로고침하거나 제거할 수 있습니다. 메타데이터는 `metadata.bookmark`에 저장되고 제목, 설명, URL은 검색용으로 `markdown`에 요약됩니다.

공개 사이트가 자동 미리보기 요청을 차단하거나, 시간이 초과되거나, HTML이 아닌 응답을 반환하거나, 일시적으로 접속할 수 없는 경우에도 BrainVault는 원래 URL, 호스트 이름, 기본 favicon 경로가 포함된 기본 북마크를 추가합니다. 편집기는 fallback 사용을 알리고 나중에 새로고침할 수 있게 합니다.

서버 측 미리보기 fetch의 보안 세부사항은 [보안](../../security/2026-07-30/security.ko.md#북마크-미리보기-안전성)에 설명되어 있습니다.

## 비디오 블록

`/video`를 입력하고 지원되는 watch, short-form, live 또는 embed URL을 붙여넣습니다. BrainVault는 비디오 ID를 검증하고 선택적인 시작 시간을 보존하며, 제공자 API 키 없이도 반응형 privacy-enhanced player를 렌더링합니다.

원래 URL은 `markdown`에 유지되므로 검색, 협업, 버전 기록, 백업, 복원은 일반 블록 영속성 경로를 계속 사용합니다.

## 첨부파일 블록

`/file`을 입력하고 **첨부파일(Attachment)**을 선택한 뒤 파일을 선택합니다. 현재 블록에 슬래시 명령만 있으면 그 자리에서 교체되고, 그렇지 않으면 첨부파일이 아래에 삽입됩니다. 카드에는 원래 파일명, 미디어 유형, 크기, 인증된 다운로드 버튼이 표시됩니다.

업로드된 바이트는 기본값이 `uploads/`인 `ATTACHMENT_UPLOAD_DIR` 아래에 저장됩니다. 기본 최대 파일 크기는 25 MB이며 `MAX_ATTACHMENT_SIZE_MB`로 변경할 수 있습니다. 커밋된 첨부파일 저장 공간은 기본 2048 MB인 `ATTACHMENT_STORAGE_MAX_MB`에 따라 계정별로 제한되고, 추가로 5,000개 파일이라는 고정 제한이 있으며 두 제한은 백업 복원 시에도 적용됩니다.

첨부파일 저장 및 삭제 규칙은 [보안](../../security/2026-07-30/security.ko.md#첨부파일-안전성)에 설명되어 있습니다.

## 전체 백업 및 복원

**설정(Settings) → 데이터(Data)**를 열어 전체 BrainVault 백업을 다운로드하거나 BrainVault가 내보낸 아카이브를 복원할 수 있습니다.

ZIP에는 계정 워크스페이스 그래프가 포함됩니다. 일반/보관 페이지, 컬렉션, 중첩 블록, 블록 메타데이터, 페이지/태그 관계, 협업자 계정 ID와 사용자 이름에 연결된 페이지 공유 권한과 컬렉션 공유 권한, 사용자가 볼 수 있는 페이지 Version 기록, 소유 페이지 탐색 접힘 상태, 지원되는 프로필 환경설정, 계정 첨부파일 업로드 디렉터리에 실제로 남아 있는 모든 파일의 원래 바이트열, 사용자 지정 페이지 커버 바이트, 계정이 소유한 모든 업로드 사용자 지정 이미지 아이콘 파일이 들어갑니다. 현재 v4 내보내기는 복원 시 페이지 교체 cascade로 제거될 수 있는 페이지 기록 행과 탐색 상태를 보존합니다. v3 자산 형식은 v4 안에도 유지됩니다. 실시간 블록에서 참조하는 첨부파일은 일반 `attachments`, 추가로 안전하게 보존된 업로드 파일은 `retainedAttachments`, digest에 연결된 `custom-icons/` 항목에는 picker에서 제거되었지만 immutable 참조를 위해 의도적으로 유지한 업로드 아이콘 파일이 포함됩니다. 로컬 `/upload/icons/<userId>/...` 값은 실시간 페이지/프로필 필드와 페이지 Version 기록 모두에서 가져오기 대상 계정 ID로 다시 연결되므로, 잃어버린 서버에서 만든 백업을 내부 ID가 다른 새 계정으로 복원할 수 있습니다. v3 업로드 자산 백업, v2 사용자 지정 커버 백업, v1 인라인 커버 백업도 계속 가져올 수 있습니다. 내보내기 전에 BrainVault는 same-origin 탭을 조정하고, 소유 페이지에 저장되지 않은 직접 초안 또는 브라우저 저장소의 확인되지 않은 실시간 복구 스냅샷이 남아 있으면 불완전한 아카이브 생성을 거부합니다.

복원은 현재 계정의 워크스페이스 내용을 교체합니다. 로그인 사용자 이름, 비밀번호 해시, authenticator 비밀값, 패스키, 기타 보안 자격 증명은 내보내지 않으며 그대로 유지됩니다. 현재 형식 백업에서 참조하는 모든 협업자는 대상 서버에 동일한 계정 ID와 사용자 이름으로 존재해야 하며, 그렇지 않으면 워크스페이스 데이터를 교체하기 전에 복원이 실패합니다. 이전 형식의 사용자 이름 전용 공유 레코드는 현재의 정확한 page-to-account 권한과 일치해야 합니다. 공유 내보내기를 완전히 생략한 더 오래된 백업의 경우 보관 페이지에 유지된 권한을 포함해 일치하는 일반 페이지 ID에 이미 존재하는 권한을 조용히 제거하지 않고 보존합니다.

과거 Yjs 업데이트 로그는 포함되지 않습니다. 협업 콘텐츠는 내보내기 전에 완전히 materialize되어야 하며, 복원된 페이지는 내보낸 페이지 및 컬렉션 공유 권한을 다시 만드는 동안 새 협업 generation을 받습니다.

검증, staging, digest 검사, 트랜잭션 동작, 아카이브 제한은 [보안](../../security/2026-07-30/security.ko.md#백업-및-복원-안전성)에 설명되어 있습니다.

## PDF 내보내기

페이지를 열고 페이지 도구 모음에서 **PDF 내보내기(Export PDF)**를 선택합니다. BrainVault는 현재 페이지만 준비하고 편집기 전용 컨트롤을 제거하며 배경과 색상을 보존하고 가로 스크롤 표와 보드를 확장한 뒤 브라우저 인쇄 대화상자를 엽니다. 파일을 만들려면 **PDF로 저장(Save as PDF)**을 선택하세요.

인쇄 스타일시트는 가능한 경우 기본 900 px 문서 레이아웃을 그대로 유지하도록 A4 가로 페이지를 사용합니다. 매우 넓은 표, 칸반 보드, 데이터베이스 뷰, 간트 타임라인은 가로 잘림을 방지하도록 균일하게 축소됩니다.

## 언어

브라우저 인터페이스는 다음 언어를 지원합니다.

- 영어 (`en`)
- 일본어 (`ja`)
- 한국어 (`ko`)
- 프랑스어 (`fr`)
- 독일어 (`de`)
- 스페인어 (`es`)
- 포르투갈어 (`pt`)

처음 방문하면 BrainVault는 `navigator.languages`를 확인하고 브라우저에서 지원되는 첫 언어를 선택하며 일치하는 언어가 없으면 영어로 대체합니다. 로그인 후에는 사이드바 상단의 사용자 카드를 열고 **환경설정(Preferences)**을 선택해 언어를 변경할 수 있습니다.

선택한 언어는 계정과 `localStorage`의 `brainvault.language`에 저장됩니다. 번역 구현 세부사항은 [개발](../../development/2026-07-28/development.ko.md#번역)에 있습니다.
