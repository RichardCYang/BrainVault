# 機能

## ワークスペースとエディター

BrainVaultは、コンパクトな文書ツリーと自動タイトル保存を備えたページ中心のワークスペースを使用します。クラッシュ耐性のあるブラウザー下書きジャーナルが、より新しいサーバーバージョンを上書きせずに未確認のタイトル・ブロック編集を復元します。

ページとコレクションは、韓国語／英語検索、カテゴリ、肌色バリエーション、最近の選択、再利用可能な最大512 KBのカスタムPNG、JPEG、WebP、ICO画像アイコンとともにUnicode Emoji 17アイコンをサポートします。ページはネスト、アーカイブ、または3点メニューから完全削除でき、検索対象にはページタイトルとブロック内容が含まれます。

### ページカバー画像

各通常ページはタイトルの上に幅広いカバーを表示できます。`public/img/default_cover`内の5つの画像から選ぶか、PNG、JPEG、WebP画像をアップロードします。閉じているpickerはフルサイズ画像を取得せず、ダイアログを開いたときだけ小さなWebPプレビューが割り当てられます。ブラウザー側最適化は既存ページ更新APIが保存する前にカスタムカバーを2 MB以下へ制限し、サーバー検証は宣言された画像タイプとバイナリsignatureの両方を確認します。

所有者はいつでもカバーを置換または削除し、後で再追加できます。**位置調整（Reposition）**モードは直接ポインタードラッグと水平・垂直スライダーをサポートします。選択した焦点は0～100座標として永続化され、`object-fit: cover`と`object-position`でレンダリングされます。カバーのソースと位置メタデータはワークスペースのバックアップ／復元に含まれます。

## 同時編集対応のページ／コレクション共有

### 直接ページ共有

通常ページを開き、**共有（Share）**を選択してログインIDで既存BrainVaultアカウントを追加します。直接ページ共有はそのページに`EDIT`権限を作成します。直接権限を作成または取り消せるのはページ所有者だけです。実効`ADMIN`アクセスを持つユーザーは項目を確認できますが、所有者が発行したアクセスを取り消すことはできません。直接ページ共同編集者は共有ページを編集できますが、直接権限だけでは所有者の周辺ページ階層は公開されません。

アーカイブ済み通常ページは新しい直接権限を受け取れず、リアルタイム共同編集も使用できません。既存の直接権限はページのアーカイブ中も保持され、ページを復元すると再び利用できます。

### コレクション共有

**カスタムコレクション**は、既存BrainVaultアカウントへ`READ`、`WRITE`、`ADMIN`の3権限のいずれかで共有できます。権限はコレクションと、ネストされた子孫を含むその階層内のすべての文書ページへ適用されます。コレクション内で新規作成したページは権限を継承し、ページサブツリーをコレクション内外へ移動すると実効コレクション範囲が更新されます。

コレクション共有UIを開くには、サイドバーでカスタムコレクションの**名前**をクリックしてコレクションのランディングビューを表示し、**ページ追加（Add page）**の横の**コレクション共有（Share collection）**を選択します。仮想の**既定コレクション（Default Collection）**、個別文書を開いている場合、またはコレクション権限が`READ`/`WRITE`のみの共同編集者にはこのコントロールは表示されません。

| 権限 | 動作 |
| --- | --- |
| `READ` | 共有コレクションを閲覧しメンバー文書を読み取ります。ブラウザーはライブYjs変更を受信できますが、サーバー側共同編集書き込みは拒否されます。 |
| `WRITE` | 読み取りに加えて共有文書のタイトルとブロックを編集します。共有およびページ管理コントロールは利用できません。 |
| `ADMIN` | 読み書きに加え、共有コレクション範囲内でコレクション共有とメンバーページ管理を行います。そのコレクション外へのページ移動、コレクションルートの完全削除、所有者発行の直接ページ権限取り消しは拒否されます。 |

特定ユーザーについては、メンバーページの直接ページ`EDIT`権限よりコレクション権限が優先されます。そのため古い直接`EDIT`権限が存在していても、コレクション`READ`権限があればそのページは読み取り専用のままです。コレクション権限を削除すると、低優先度の直接ページ権限が再び有効になる場合があります。

通常文書に実効共同編集者が1人でも設定されている間、ページタイトルとブロック文書は認証済みWebSocket接続上のYjs共有文書を通じて同期されます。同時のテキスト／構造変更は自動的にマージされ、アクティブ共同編集者と現在の編集位置がページヘッダーへ表示され、一時切断中の編集は再接続後にマージされます。`READ`コレクション共同編集者はライブ文書と同期し続けられますが、Yjs書き込みは送信できません。

添付ファイルのバイト列は引き続き認証済みアップロード／ダウンロードAPIを使用します。サーバーは正規添付ファイルブロックをYjs roomへ公開するため、書き込み可能な共同編集者がそれを受信しつつ、クライアントによるファイルメタデータ偽造は許されません。Yjs更新はMariaDBへ永続化され、検索、レンダリング、エクスポート、バックアップ互換性のため定期的に通常ページ／ブロックテーブルへmaterializeされます。

共有ページのアーカイブ、ページサブツリーの完全削除、コレクションメンバーシップ変更、共有権限の変更／削除、ワークスペース全体の復元は、persistence transitionとrecovery fenceを調整し、古いブラウザー状態が新しいアクセスgenerationを上書きできないようにします。

プロトコルと永続化モデルについては[ページ／コレクション共有とリアルタイム共同編集](../../collaboration/2026-07-29/collaboration.ja.md)を、コレクション固有のUI、ロールモデル、継承規則、API、バックアップ動作、トラブルシューティングについては[コレクション共有](../../collaboration/2026-09-02/collection-sharing.ja.md)を参照してください。

### キーボードとブロック操作

| 操作 | 結果 |
| --- | --- |
| `Enter` | 現在のブロックの下にブロックを挿入します。 |
| `Shift + Enter` | 同じブロック内に改行を追加します。 |
| 空ブロックで`Backspace` | ブロックを削除し、ネストした子をその位置へ昇格させ、前のブロックへフォーカスを移します。ネットワーク完了が不明な場合は同じ削除receiptで再試行します。 |
| `/` | ブロック種類メニューを開きます。 |
| `Ctrl/Cmd + B` | 選択テキストへ太字を適用します。 |
| `Ctrl/Cmd + I` | 選択テキストへ斜体を適用します。 |
| `Ctrl/Cmd + Shift + M` | 選択テキストをインラインLaTeX数式で囲みます。 |
| 6点ハンドルをドラッグ | 現在の階層内でブロック順を変更します。 |

便利なスラッシュコマンドには次があります。

```text
/h1  /h2  /h3  /todo  /quote  /callout  /table  /database  /gantt  /board  /bookmark  /ai  /math  /code  /divider  /image  /file
```

インライン書式は太字、斜体、取り消し線、コード、数式、リンク、文字色、および左／中央／右／両端揃えのブロック整列をサポートします。ドラッグ＆ドロップによる並べ替えはネストされた内容にも対応します。

テーブルブロックには行、列、ヘッダー操作があります。セルは矢印キー移動をサポートし、`Enter`は現在の列を下へ進み、最後のセルで`Tab`を押すと行を追加します。

## データベースとカンバンブロック

`/database`と入力してデータベースブロックを作成します。各データベースには必須タイトルプロパティ1つと、任意のテキスト、数値、選択、複数選択、チェックボックス、日付、URLプロパティがあります。

テーブル、ボード、リストビューは同じ行を対象に動作します。各ビューは固有の名前、レイアウト、表示プロパティ、フィルター、並べ替え順、ボードグループを保存します。エディターにはビュータブ、Properties/Filter/Sort popover、ビュー内検索、分割Newボタン、透明な列ヘッダー、色付きselect pillがあります。

プロパティと行の変更は`metadata.database`に保存され、検索可能なテキスト要約は`markdown`へ保持されます。

カンバンボードはタイトル、グループ、カードの直接編集をサポートします。カードは絵文字と、既定、ピンク、黄、青、薄緑、紫、ピーチのパステルテーマを使用できます。6点カードハンドルをドラッグしてカードを並べ替えたりグループ間で移動したりできます。矢印操作はタッチ端末やキーボード利用者へ同等の移動機能を提供します。

## ガントタイムラインブロック

`/gantt`と入力すると、固定タスクテーブルと横スクロール可能な日付グリッドを組み合わせたプロジェクトタイムラインを作成できます。各タスクはタイトル、ステータス、担当者、開始／終了日、進捗率を保存します。

週、月、四半期スケールを利用し、今日へジャンプしたり隣接日付範囲へ移動したり、任意で週末を網掛けできます。タスクバーをドラッグするとスケジュール全体を移動し、左右端をドラッグすると期間を調整できます。左右矢印キーも利用できます。`Shift`を押しながら矢印キーを押すと、タスク移動ではなく終了日を調整します。

ガントデータは`metadata.gantt`に保存され、長さを制限した平文要約が`markdown`へ保持されるため、ページ検索でタイムラインタイトル、タスク、ステータス、担当者、日付、進捗を検索できます。

## LaTeX数式

`/math`と入力すると、ライブKaTeXプレビュー付きの中央揃えdisplay-formulaブロックを作成できます。たとえば次のように、周囲の区切り文字なしでソースを入力します。

```text
\frac{-b \pm \sqrt{b^2-4ac}}{2a}
```

インライン数式はテキストを選択して`∑`ツールバーボタンを押すか、`Ctrl/Cmd + Shift + M`を使用します。BrainVaultが選択範囲を`\(...\)`で囲みます。Markdownブロックは`$...$`と、`$$...$$`で区切られたdisplay数式も認識します。

数式レンダリングはサニタイズされ、trusted commandsを無効化したKaTeXを使用します。

## AI会話ブロック

`/ai`と入力すると、質問とAI回答を左右2方向のチャットtranscriptとして保存できます。質問は右寄せbubble、回答はAI識別情報と応答メタデータを持つ左寄せbubbleとして表示されます。

アイコンpickerには設定済みAIプロバイダーの選択肢が表示されます。プロバイダーアイコン、自由形式のモデル名、ローカル回答日時、質問、回答は`metadata.aiChat`に保存されます。長さを制限したテキスト要約も`markdown`へ書き込まれるため、プロバイダー、モデル、質問、回答を検索できます。読み取りモードでは会話表示を保ちながら設定コントロールを隠します。

## ブックマークブロック

`/bookmark`と入力してWebブックマークコレクションを作成します。HTTPまたはHTTPS URLを貼り付けるとBrainVaultがサーバーでページメタデータを取得します。

ブロックは2種類のビューをサポートします。

- **リスト（List）:** faviconとタイトルを含むコンパクトな行
- **ギャラリー（Gallery）:** OpenGraphサムネイル、タイトル、説明、favicon、サイト名を含むレスポンシブカード

ブックマークは更新または削除できます。メタデータは`metadata.bookmark`へ保存され、タイトル、説明、URLは検索用に`markdown`へ要約されます。

公開サイトが自動プレビュー要求をブロックする、タイムアウトする、非HTML応答を返す、一時的に到達不能である場合でも、BrainVaultは元URL、ホスト名、既定faviconパスを含む基本ブックマークを追加します。エディターはfallback使用を通知し、後で更新できるようにします。

サーバー側プレビューfetchのセキュリティ詳細は[セキュリティ](../../security/2026-07-30/security.ja.md#ブックマークプレビューの安全性)に記載されています。

## 動画ブロック

`/video`と入力して対応するwatch、short-form、live、embed URLを貼り付けます。BrainVaultは動画IDを検証し、任意の開始時刻を保持し、プロバイダーAPIキーなしでレスポンシブなprivacy-enhanced playerをレンダリングします。

元URLは`markdown`へ残るため、検索、共同編集、バージョン履歴、バックアップ、復元は通常のブロック永続化経路を引き続き使用します。

## 添付ファイルブロック

`/file`と入力し、**添付ファイル（Attachment）**を選び、ファイルを選択します。現在のブロックがスラッシュコマンドだけの場合はその場で置換され、それ以外では添付ファイルが下に挿入されます。カードには元ファイル名、メディアタイプ、サイズ、認証済みダウンロードボタンが表示されます。

アップロードされたバイト列は、既定値が`uploads/`の`ATTACHMENT_UPLOAD_DIR`配下へ保存されます。既定の最大ファイルサイズは25 MBで、`MAX_ATTACHMENT_SIZE_MB`で変更できます。コミット済み添付ファイルストレージは、既定2048 MBの`ATTACHMENT_STORAGE_MAX_MB`によりアカウントごとに制限され、さらに固定5,000ファイル制限があります。両制限はバックアップ復元時にも適用されます。

添付ファイルの保存と削除規則は[セキュリティ](../../security/2026-07-30/security.ja.md#添付ファイルの安全性)に記載されています。

## 完全バックアップと復元

**設定（Settings）→ データ（Data）**を開き、BrainVaultの完全バックアップをダウンロードするか、BrainVaultがエクスポートしたアーカイブを復元します。

ZIPにはアカウントのワークスペースグラフが含まれます。通常／アーカイブページ、コレクション、ネストブロック、ブロックメタデータ、ページ／タグ関係、共同編集者アカウントIDとユーザー名に結び付いたページ共有権限およびコレクション共有権限、ユーザーに見えるページVersion履歴、所有ページのナビゲーション折りたたみ状態、対応プロファイル設定、アカウント添付ファイルアップロードディレクトリに物理的に保持されている全ファイルの元バイト列、カスタムページカバーバイト、アカウント所有のアップロード済みカスタム画像アイコンファイルが入ります。現在のv4エクスポートは、復元時のページ置換cascadeで通常は削除されるページ履歴行とナビゲーション状態を保持します。v3アセット形式はv4にも組み込まれています。ライブブロックから参照される添付ファイルは通常の`attachments`、追加で安全に保持されたアップロードファイルは`retainedAttachments`、digestに結び付く`custom-icons/`項目にはpickerから削除されてもimmutable参照のため意図的に保持されたアップロードアイコンが含まれます。ローカル`/upload/icons/<userId>/...`値は、ライブページ／プロファイルフィールドとページVersion履歴の両方でインポート先アカウントIDへ再バインドされるため、失われたサーバー上で作成したバックアップを内部IDが異なる新規アカウントへ復元できます。v3アップロードアセットバックアップ、v2カスタムカバーバックアップ、v1インラインカバーバックアップも引き続きインポートできます。エクスポート前にBrainVaultはsame-originタブを調整し、所有ページに未保存の直接下書き、またはブラウザーストレージ内に未確認のリアルタイム復旧スナップショットが残っている間は、不完全なアーカイブ作成を拒否します。

復元は現在アカウントのワークスペース内容を置き換えます。ログインユーザー名、パスワードハッシュ、authenticatorシークレット、パスキー、その他のセキュリティ認証情報はエクスポートされず変更されません。現行形式バックアップで参照されるすべての共同編集者は、対象サーバー上に同じアカウントIDとユーザー名で存在する必要があります。そうでなければワークスペースデータを置換する前に復元が失敗します。旧形式のユーザー名のみの共有レコードは、現在の正確なpage-to-account権限と一致する必要があります。共有エクスポートを完全に省略した古いバックアップでは、アーカイブページに保持された権限を含め、一致する通常ページIDに既に存在する権限を暗黙に削除せず保持します。

過去のYjs更新ログは含まれません。共同編集コンテンツはエクスポート前に完全にmaterializeされる必要があり、復元ページはエクスポート済みページ／コレクション共有権限を再作成する際に新しい共同編集generationを受け取ります。

検証、staging、digestチェック、トランザクション動作、アーカイブ制限は[セキュリティ](../../security/2026-07-30/security.ja.md#バックアップと復元の安全性)に記載されています。

## PDFエクスポート

ページを開き、ページツールバーで**PDFエクスポート（Export PDF）**を選択します。BrainVaultは現在ページだけを準備し、エディター専用コントロールを削除し、背景と色を保持し、横スクロール可能なテーブル／ボードを展開して、ブラウザーの印刷ダイアログを開きます。ファイルを作成するには**PDFとして保存（Save as PDF）**を選択してください。

印刷スタイルシートは、可能な限り既定の900 px文書レイアウトを変更しないようA4横向きページを使用します。非常に幅広いテーブル、カンバンボード、データベースビュー、ガントタイムラインは横方向のクリッピングを防ぐため均等に縮小されます。

## 言語

ブラウザーインターフェースは次の言語をサポートします。

- 英語 (`en`)
- 日本語 (`ja`)
- 韓国語 (`ko`)
- フランス語 (`fr`)
- ドイツ語 (`de`)
- スペイン語 (`es`)
- ポルトガル語 (`pt`)

初回訪問時、BrainVaultは`navigator.languages`を確認し、最初に一致した対応ブラウザー言語を選択します。一致がなければ英語へフォールバックします。サインイン後はサイドバー上部のユーザーカードを開き、**設定（Preferences）**を選択して言語を変更できます。

選択した言語はアカウントと`localStorage`の`brainvault.language`へ保存されます。翻訳実装の詳細は[開発](../../development/2026-07-28/development.ja.md#翻訳)にあります。
